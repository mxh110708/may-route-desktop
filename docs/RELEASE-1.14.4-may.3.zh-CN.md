# May Route 1.14.4-may.3

修复组页面长节点名称被省略，容易混淆 IPv4／IPv6 入口或落地的问题。桌面基于 sing-box 1.14.4，配套核心继续固定 1.14.4-may.1。

- 参考当前最长节点名称的显示宽度，加上卡片边距和额外余量，将统一基准宽度设为 320 CSS 像素。窗口变宽自动增列、变窄自动减列，不设列数上限。同一可用宽度下，名称长短不会改变各组列数；不足一整行时仍保留列宽。
- 完整名称在卡片内换行，不再用省略号隐藏末尾的出口标识；不新增悬停提示。
- 同一行按最高卡片统一高度，协议与延迟在底部对齐。窄卡片中的元数据可以换行，避免相互覆盖。

本次仅调整显示布局，沿用原节点标识、配置、选择与故障切换逻辑。显示完整不改变 IPv6 落地对目标网站的兼容性。may.2 的入口组记忆和系统代理守护修复继续包含在本版中。
