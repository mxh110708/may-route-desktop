# MXH Route 1.14.2-mxh.12

修正 Windows 托盘左右键分工和子菜单交互。

- 左键单击打开主界面；窗口已最小化时恢复，托盘菜单已打开时先收起菜单。
- 右键单击打开托盘菜单。
- 改用原生级联菜单：悬停展开子菜单、父菜单保持可见，边缘翻转和键盘导航由平台菜单处理。
- 移除重复的双击处理，避免双击通知再次触发打开操作。
- 保留系统代理/TUN、路由模式、节点测速、配置切换和远程更新等操作。配置变化会关闭旧菜单，再次打开读取当前节点。
- 菜单跟随应用深浅色设置，使用系统菜单字体；主界面的文楷与字体导入继续保留。

增加八项事件与菜单回归测试，并纳入正式构建与 GitHub 检查。另使用真实原生菜单对象验证级联结构和操作接线，替换托盘图标与菜单弹出，没有显示测试菜单或操控用户鼠标。详细范围见 `docs/NATIVE-TRAY-2026-10-17.zh-CN.md`。

安装包沿用既有签名身份，Release 附 SHA-256 校验文件。
