# MXH Route 深浅色主题重构

更新：2026-10-17。

## 设计与范围

界面参考 MXH VPS Deploy 的 `DesktopTheme`，沿用 MXH Route 既有导航、组件与主题偏好：

- 深色使用蓝灰内容底色、稍亮卡片、深色侧栏及浅蓝强调色；避免纯黑与亮白控件混在一起。
- 浅色使用蓝色侧栏、白色内容区、浅灰蓝卡片及蓝色强调色。
- 侧栏文字、图标、悬停和选中项具有独立颜色角色；内容文字、输入框、普通按钮、弹层和标题栏分别使用自己的颜色角色。
- 卡片和控件采用较克制的圆角、边界与阴影；输入、选中、禁用、焦点状态与整套配色一致。
- 侧栏间距增大后，桌面最小高度下允许滚动导航，保证末尾设置入口可达。

公共样式在 Dashboard 子模块内维护：`src/styles/globals.css` 定义主题令牌，`src/styles/shared.css` 定义共享控件；`App.module.css` 与 `DesktopToolbar.module.css` 分别消费导航和标题栏令牌。浏览器初始颜色、PWA 清单及运行时 `theme-color` 使用相同的标题栏／内容区配色。

默认主题色从中性黑白调整为 MXH 蓝色系；已保存的深色、浅色、跟随系统、预设主题色与自定义颜色继续生效。终端的独立配色方案继续由终端设置管理。此轮没有修改代理规则、连接、故障切换、服务或系统代理接管实现。

## 验证与边界

在 BERO 执行 Dashboard 的 `pnpm lint`、`pnpm lint:css`、`pnpm test`、`pnpm build`，以及桌面项目的 `pnpm typecheck`、`pnpm build`；现有 10 个测试文件、71 项测试通过。最后的侧栏与控件状态样式修正另外执行 CSS 检查和两个前端构建。

浏览器预览运行真实 `App`、桌面外壳、视图及控件，仅将宿主和 API 替换为本地合成数据，不连接真实代理服务。实际检查：

- 概述、展开／折叠分组、设置页、下拉和主题色菜单。
- 深浅色切换、键盘 Tab 焦点及 Enter 切换、刷新后保留偏好。
- 新建配置弹窗的输入、主次按钮、禁用状态与取消操作。
- 721 × 320 桌面最小窗口：分组区无横向溢出，侧栏可滚动访问设置。
- 两种默认主题各 16 组正文、辅助文字、按钮、导航和状态标签对比度均不低于 4.5:1；浅色最低 4.59:1，深色最低 5.52:1。该结论仅适用于检查的默认颜色组合，不代表任意自定义颜色都具有相同对比度。

浏览器检查覆盖渲染层，不代替 Windows 原生窗口按钮、托盘或安装器验收。本轮未操作正在使用的系统代理／TUN；未发布或替换正式安装包。
