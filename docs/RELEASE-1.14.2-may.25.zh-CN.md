# May Route 1.14.2-may.25

修复 Windows 守护进程读取状态时反复应用系统代理的问题。这条路径可能在代理值未变化时触发 WSL 的 HTTP 代理变更通知，也会绕过桌面层对其他代理客户端接管的避让保护。

- 同一用户、同一 Windows 会话的状态读取和订阅授权不再写入、关闭或抢回系统代理。
- 手动重新启用仍可恢复被其他客户端改过的代理；真实拥有者交接、配置初始化、关闭和失败回退保持原有行为。
- 不增加常驻轮询、额外进程或注册表查询；不修改 WSL 的自动代理设置、现有分流规则及故障切换策略。

隔离测试已先复现旧实现两种入口各 100 次读取触发 100 次代理启用调用，修复后为零写入；同时覆盖开启、关闭、明确恢复、写入失败、会话交接和释放。完整标签下的相关核心测试、35 项桌面代理守护测试、6 项安装隔离测试及 Windows 守护进程编译通过；新增回归已纳入核心 CI 和正式构建前检查。详细范围见 [排查与修复说明](WINDOWS-PROXY-NOTIFICATIONS-2026-10-23.zh-CN.md)。

安装包沿用现有 May 安装身份与签名，保留用户配置、字体和故障切换设置，附 SHA-256 校验文件。本次仅推送发布，由用户手动更新；没有安装、重启现用服务、切换系统代理或操作鼠标。实际 WSL 通知是否停止仍须在更新后观察。
