# 简中、英文与资源清理（2026-10-18）

版本归档：经后续逐项复核保留的改动收入 `1.14.2-mxh.17`，见 [发布说明](RELEASE-1.14.2-mxh.17.zh-CN.md)。下文发布状态与实验结论记录的是当轮情况，最终保留判断以 [逐项实测](INDIVIDUAL-PERFORMANCE-2026-10-19.zh-CN.md) 为准。

> 2026-10-19 补测更正：本文基于 Windows 累计进程时间的 CPU 百分比保留为历史记录，不再用于证明改善或回退幅度。周期计数与 GPU 跟踪见 [CPU 计时复核](GPU-MEASUREMENT-2026-10-19.zh-CN.md)；内存、功能及调用次数分别判断。

本轮继续常驻开销优化，并将 May Route 的界面支持收敛为简体中文和英文。上一轮文楷按需解码、故障切换分析缓存和概述精简接口仍保留，说明见 [常驻内存验收](RESIDENT-MEMORY-2026-10-18.zh-CN.md)。本轮测试基线已包含这些未发布改进，避免将前一轮收益再次算作语言清理收益。

## 支持范围与旧设置

- 语言选项保留「跟随系统」「English」「简体中文」。
- 自动模式按浏览器支持的语言优先顺序选择中、英文；中文区域和繁中系统标签使用简中，找不到支持的语言时使用英文。
- 已保存的 `zh-Hant` 读取为 `zh-Hans`，已保存的 `fa`、`ru` 读取为 `en`；缺失或其他无效设置继续使用自动模式。无需用户手动清理配置。
- 原生托盘、终端右键菜单与发给核心的语言使用同一回退策略。核心只注册英文、简中两份消息，保留区域标签、系统 locale、Accept-Language 权重及无效输入的兼容处理。
- Chromium 资源限定 `en-US`、`zh-CN`，NSIS 安装器限定 `en_US`、`zh_CN`，安装器中的其他自定义翻译也已移除。

仅删除产品翻译与其布局支持。节点名称、配置文本、日志、终端输出和用户字体仍可包含其他语言；文楷完整原始字体及 46,490 字符覆盖保持不变。

## 常驻资源变化

界面 474 条译文、原生界面 72 条译文均改为「英文消息键 → 简中字符串」。不再为每条消息创建多语言对象，不再加载繁中、波斯语和俄语字典。英文直接使用消息键。简中不需要复数分类，移除相应的 `Intl.PluralRules` 缓存和分支，参数占位符替换保持一致。

源文件大小用于复现清理范围，不作为运行内存收益：

| 项目 | 清理前 | 清理后 |
| --- | ---: | ---: |
| dashboard 翻译模块 | 91,616 B | 22,956 B |
| 原生翻译模块（含兼容处理） | 11,866 B | 3,100 B |
| 安装器额外翻译 | 254 条其他语言文本 | 已移除 |

生产构建的初始 JavaScript 总量由实际加载审计计算，包含入口及其同步共享块：

| 入口 | 清理前 | 清理后 |
| --- | ---: | ---: |
| 主界面 | 664,882 B | 603,409 B |
| renderer 托盘 | 536,020 B | 474,547 B |

两个入口均少加载 61,473 B。Windows 使用原生托盘菜单；renderer 托盘的数值不表示 Windows 后台额外常驻了一个托盘窗口。终端、Markdown、文楷范围表及不常用页面继续通过已有生产构建审计约束为延迟模块。

## 四种状态的本轮增量对照

以包含上一轮字体、缓存改进的源码快照为「清理前」。每种状态前后各两轮，第二轮反转先后顺序，共 16 次运行、64 个样本。相同 Electron 43.4.1、硬件加速、1280×800 视口、完整文楷覆盖和 201,890 B 合成配置。准备界面后等待 18 秒，每轮采四次进程树私有工作集；CPU 根据采样区间累计 CPU 增量计算，以一个逻辑核心为 100%。

| 状态 | 清理前内存中位数 | 清理后内存中位数 | 清理前 CPU | 清理后 CPU |
| --- | ---: | ---: | ---: | ---: |
| 代理运行、前台 | 151.06 MiB | 148.40 MiB | 2.87% | 3.01% |
| 代理停止、前台 | 125.06 MiB | 118.54 MiB | 0.10% | 0.43% |
| 代理运行、后台 | 142.53 MiB | 138.09 MiB | 2.02% | 2.15% |
| 代理停止、后台 | 119.99 MiB | 117.04 MiB | 0.57% | 0.48% |

内存为每格八个样本的中位数，CPU 为两轮区间计算结果的中位数。该组样本的内存差值为约 2.7–6.5 MiB，CPU 没有稳定下降，不能将源代码简化直接当作 CPU 收益。工作集仍随 V8 回收、GPU 和系统状态波动：例如运行中前台的末次样本，两轮中位数从 146.14 MiB 变为 150.31 MiB，方向与全样本中位数不同，因此不承诺每一时刻都更低。

测试自己的真实回环代理持续传输并校验了 94,175,232 B，零传输错误；每轮还替换配置并通过实际状态接口确认节点刷新。`summary.json` 保留全部样本和按进程分类的统计。

原生测试窗口始终隐藏，前台由文档可见性模拟。统计包含隔离 Electron 与自有代理后端，不包含现用 Windows 特权 relay、应用辅助进程或现用客户端。两组都保持界面实例，不销毁窗口换取低数值。这些结果用于本轮增量对照，不等于用户任务管理器里的安装版绝对值，也不是长期内存上限。核心本轮语言清理通过 Go 测试验收，对照用的自有代理后端保持同一二进制以控制变量。

## 验收与限制

新增测试核对语言集合、旧设置回退、中文区域识别、参数占位符、系统语言变更订阅、原生翻译以及 Chromium/安装器资源配置。核心测试覆盖注册集合、中英文选择、旧中文标签、带编码的系统 locale、语言优先权重、q=0 及无效输入。

隐藏的真实 Chromium 界面核对了三个语言选项、中英切换、旧繁中/俄语/波斯语设置回退、LTR 布局和未保存的更新代理地址草稿。原有功能验收继续覆盖 Markdown 格式与转义、日志暂停/恢复、字体切换、迟到字体清理、终端输入以及同一终端在后台和主题切换后的会话保留。终端传输使用合成实现，不能据此声称已验证真实 SSH。

157 项桌面 Node 测试、99 项界面测试，TypeScript、界面 JS/TS 与 CSS lint、安装器目录恢复检查和生产构建均通过；Go 核心 locale 与 daemon 测试通过。新的桌面语言测试已加入 CI 和签名打包前检查，核心语言测试已加入核心 CI。

测试记录保存在工作区 `.codex-tmp/route-language-memory-pass5-20261018/`，界面结果为 `functional-verification.json`，检查结果为 `checks.json`，构建结果为 `production-build.log`。该目录用于本机复核，不属于发布资源。

本轮初次隔离测试曾向已关闭的启动管道写日志，产生 `EPIPE` 弹窗；之后测试日志改为独立文件并捕获测试异常，重跑通过。没有为了处理该测试弹窗而修改产品异常处理或隐藏产品错误。

现用客户端未替换，源码尚未提交和发布。
