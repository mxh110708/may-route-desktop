# May Route 1.14.2-mxh.8

更新深浅色界面，并为应用更新增加独立的代理连接设置。继续基于 sing-box 1.14.2。

- 深色使用蓝灰分层和浅蓝强调色，浅色使用蓝色侧栏和白色内容区；统一卡片、输入框、按钮、菜单与对话框的颜色及状态，保留跟随系统、预设和自定义主题色。
- 优化侧栏、标题栏、控件尺寸和小窗口滚动，调整焦点、悬停及禁用状态的可辨识度。
- 在“设置 → 应用 → 更新”下新增“更新连接”折叠项，可保存无需认证的 HTTP、HTTPS 或 SOCKS5 代理，支持 IPv6 代理地址。留空保存或点击“恢复直连”可清除设置。
- 自动及手动版本检查、安装包下载共用保存的更新代理；设置重启后保留。无效地址不会覆盖已保存配置，更新期间不能切换代理。
- 更新流量使用独立连接会话，不修改系统代理、核心配置、订阅或规则下载设置。指定代理不可用时明确报错，不自动回退直连。原有更新源、安装包大小、版本和签名校验保留。

验证包括更新相关 13 项测试、现有界面 71 项测试、类型检查、样式检查和完整构建；在 BERO 使用真实 Electron 网络栈与本地 HTTP、HTTPS、SOCKS5 代理验证版本查询、重定向、流式 HTTP(S) 下载、代理失败及恢复直连。界面通过真实 React 组件的隔离预览核对深浅色、保存、错误提示、重新打开回显和忙碌状态；未切换正在使用的系统代理或 TUN。

如果更新代理指向 Route 自身端口，需要先保持核心运行；核心未启动时，启动自动检查可能失败，可以稍后手动检查。更新前的旧客户端尚无该设置，可使用原有检查更新或从本页下载安装包。

安装包沿用既有 May Route 签名身份。发布不自动安装，请核对随 Release 提供的 SHA-256 校验文件。
